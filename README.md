# Student Score Prediction

This project demonstrates how we can predict a student's test score based on the number of hours they studied using a **Linear Regression** model. The project uses the **scikit-learn** library to train and test the model.

## Steps:
1. Create a dataset of hours studied vs. scores.
2. Train a Linear Regression model.
3. Predict the score for a given number of hours studied.
4. Compare the predicted score with a manual calculation using the linear regression formula.
